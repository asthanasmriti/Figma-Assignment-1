# Figma Assignment-1 - Portfolio Website

This repository contains a fully responsive frontend developer portfolio built using HTML5 and CSS3 based on Figma specifications.

## Features Included
- Sticky navigation bar with branding and smooth anchor links
- Hero introductory section with custom illustration for **Smriti Asthana**
- 6-card project showcase grid complete with technology tags
- Testimonial recommendations grid with star ratings and indicator dots
- Contact form paired with information address cards
- Partner logos strip and multi-column footer
- Fully responsive layout optimized for laptops, tablets, and smartphones

## Setup & Running
1. Clone or download the repository.
2. Ensure your images are placed in the `images/` directory matching the source references.
3. Open `index.html` in any web browser or use Live Server in VS Code.
